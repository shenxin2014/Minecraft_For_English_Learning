# M1：离线可视化课堂交付

日期：2026-11-25。范围：M1-01 至 M1-05。

## 使用方法

运行 `scripts/start_m1.ps1`，打开 http://127.0.0.1:8000/。
点击“去农场玩”后开始。课程按孩子的操作推进，无强制倒计时。
保持服务窗口打开；Ctrl+C 停止服务。仅绑定本机回环地址。

- 介绍阶段：看动物、听短句，观察好了再继续。
- 辨认阶段：听指令，再点击动物；画面不显示目标词。
- 再听一遍：重复当前语音，听力任务按 H1 记录。
- 帮帮我：H1 慢速重播、H2 动作线索、H3 短暂高亮、H4 Lily 指引。
- H2 采用规格允许的动作线索，没有伪称使用真实动物录音。
  课程 JSON 中旧的 PLAY_ANIMAL_SOUND 标识保持兼容，页面映射为自然动作提示。
- 暂停：立即停声；继续后恢复未完成的播放。
- 先跳过：无惩罚，不给被跳过任务奖励。
- 自愿口语：可以跟念后继续，也可以直接继续；没有麦克风或识别评分。
  页面继续走 SKIP 路径，不伪造 SPEECH_RECOGNIZED。
- 自由探索：点动物、种小花，不计听力成绩。
- 完成：查看本次观察，剧情结果与理解记录分开。

## 资源与实现

页面采用 HTML/CSS/ES modules，无外部 CDN、远程字体或运行时 npm 依赖。
SVG 场景包含农场、草地、果树围栏。图像由项目代码绘制，可直接维护。
12 段固定语音使用本机 Microsoft Zira en-US 合成，位于 `frontend/assets/audio`。
`manifest.json` 记录声线、文字与语速，`scripts/generate_audio.ps1` 可重新生成。
这是合成语音，不是真人录音或儿童语音质量验证。

HTML 音频只在 ended 后上报 AUDIO_FINISHED；启动播放、暂停、取消都不算完成。
加载/解码失败及 20 秒未结束走 AUDIO_FAILED。自动播放被浏览器拒绝时先请求用户点击播放，
不直接算作失败或呈现。H1 使用 0.88 倍播放速率。
画面解码且目标可见后才报告视觉锚点；标签隐藏或播放时目标离开视野会暂停。

前端保存当前 session_id、原始待确认事件和随机布局。断线后沿用同一个 event_id 重试，
不从客户端推算成绩。Web Locks 限制同源多页同时控制课堂。
开门与装饰奖励以幂等状态展示，不按重投次数叠加。

## 验证

- 后端 53 项测试通过，包括原 M0 35 项。
- 前端 17 项测试通过：结束/暂停/失败回执、自动播放限制、旧 Promise、网络重试、
  创建幂等、认证、fetch 调用绑定、布局恢复、答案文字隔离及暂停播放门槛。
- Ruff、ESLint、Prettier、Python 职责说明检查通过。
- 12 段 WAV 均检查为 22050 Hz、16 bit、单声道、非静音；浏览器 Range 请求返回 206。
- 浏览器 1280×900 跑通完整首课：错误选择、H1–H3、正确选择、换背景、口语跳过、
  自由种花、结束复习及家长观察。
- 浏览器实际检查播放中暂停、继续和刷新恢复。
- 390×844 检查实际介绍画面及完成页面，动物可见、按钮可操作，无横向溢出。
- 本次手工测试报告为 cow 独立 2 / 提示 1，pig 独立 2 / 提示 0，与操作一致。
  这些是开发者模拟操作，不是儿童学习成效数据。

现有 Starlette/HTTPX 测试依赖仍有一条弃用警告，未屏蔽，不影响当前通过结果。
浏览器听力流程验证不等于真人声线质量评审，仍需家长试听与亲子可用性观察。

## 边界

M1 页面是独立于 Minecraft 的可运行教学客户端，不是可导入游戏的行为包。
未实现真实语音识别、跨天复习安排和记录删除界面；分别属于后续阶段。
网络回退指不依赖云端；本地 FastAPI 不运行时暂停提交，恢复后重试，不虚构离线成绩。
代码参考：[媒体 play](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/play)、
[媒体 ended](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/ended_event)、
