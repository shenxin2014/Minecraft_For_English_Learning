## 启动与复核

在项目根目录运行：

```powershell
.\scripts\test.ps1
.\scripts\run_mock_demo.ps1
.\scripts\run_mock_demo.ps1 -AudioFails
.\scripts\start_backend.ps1
```

接口请求样例见 README。模拟演示没有真实声音，执行时间也不等于儿童的 15–20 分钟课程体验。
