# 常见问题

## 安装与启动

| 现象 | 检查与处理 |
| --- | --- |
| 找不到 `py` 或 Python 3.12 | 检查 `py -3.12 --version`；安装包含 Python Launcher 的 Python 3.12，重开终端 |
| 找不到 `.venv\Scripts\python.exe` | 在仓库根目录先运行 `scripts/setup.ps1`；Git 不上传虚拟环境 |
| PowerShell 脚本被设备策略阻止 | 遵循设备管理策略；可使用[开发指南](../CONTRIBUTING.md)中的等价 Python 命令 |
| 提示缺少 Node 或 npm | 课堂不需要 Node；完整开发检查需要 Node.js 24，执行 `npm ci` |
| 8000 端口占用 | 启动时使用 `-Port 8001`，页面与 BDS 配置同步使用新端口，不直接结束未知进程 |
| 页面打不开 | 保持启动终端运行，检查 Uvicorn 地址，访问与端口一致的回环 URL |
| 出现 401 | 操作员使用 X-API-Token；BDS 使用 X-BDS-Token，两种令牌不能互换 |
| BDS 接口返回 503 | BDS_TOKEN 未启用；使用 `start_m2.ps1` 或 `start_m3.ps1` 启动配套 API |

## 离线课堂与声音

- 首次使用先点击“开始”或“启用声音”；浏览器可能限制自动播放。
- 检查标签页、系统输出设备和音量。页面音量下限只约束页面控件，不能检测系统静音。
- 播放中暂停不会生成 AUDIO_FINISHED；恢复可能从头播放，这是避免假成功的预期行为。
- 播放文件失败会进入支持路径，不记录有效呈现，不会因沉默卡在口语任务。
- 刷新后未确认请求会重试原 ID。不要手动清理待发送事件来跳过网络错误。
- `.\scripts\run_mock_demo.ps1` 演示完整模拟课次；它不证明真实媒体或 Minecraft 已工作。

## Bedrock / BDS 候选

目标是国际版 Bedrock + BDS。Java Edition、Minecraft Education、Realms 和普通单人客户端不是当前网络行为包的替代运行环境。

```powershell
.\scripts\check_m2_environment.ps1 -BdsPath 'D:\MinecraftBDS'
```

脚本读取安装信息和指定服务端文件，最终版本与模块加载情况以 BDS 日志为准。

| 现象 | 检查顺序 |
| --- | --- |
| 模块版本无法加载 | 核对 BDS 实际版本、`profiles.json` 与日志；候选不是通用兼容保证 |
| server-net/admin 不可用 | 确认运行在 BDS、世界开启 Beta APIs、当前脚本 UUID 下权限配置正确 |
| HTTP 探针失败 | 检查 API 进程、端口、回环 URL、秘密配置及来源白名单 |
| 安装器拒绝覆盖 | 保护已有测试配置的预期行为；使用独立测试世界/目录，按文档保留旧数据 |
| 建图失败或区域不空 | 使用新的平坦创造模式测试世界，站在空旷位置；不在常用存档反复尝试 |
| 玩家绑定失败 | 先建图、等待探针成功，再运行 bind；同一世界不可静默换人 |
| 交互没有回传 | 先看原生事件日志；M2 用成功饲喂诊断，M3 使用交互前意图，实际按键需实测 |

不要绕过版本/权限错误改用未经验证的私有协议，也不要把模拟心跳写成实机证据。

## M3 伴随页一直等待

1. 确认 BDS 候选包已加载，`farm:probe` 成功，`farm:bind` 已绑定当前玩家。
2. 页面课堂编号与安装时的 `--bridge-id` 完全一致。
3. 课次没有暂停/退出，目标动物处于当前维度和视野，且无遮挡。
4. 听力随机辨认时，两只动物均须满足可见性；走得太近时退回观察位置再重听。
5. API 和游戏之间心跳未过期。恢复后旧播放代次失效，需要重新实际播放。

页面失去焦点是返回 Minecraft 的正常操作，不会仅因隐藏页面就停声。
服务器几何检查无法判断游戏窗口遮挡或最小化；真实显示行为仍需实机校准。
课堂编号填错时刷新伴随页再输入；同一课次只允许一个伴随页持有语音播放锁。

## 提交问题需要的信息

提供项目版本、运行方式、Python/Node 版本、客户端/BDS 版本、复现步骤、预期与实际结果及脱敏错误片段。
只附必要日志；不要上传 `data/`、数据库、BDS `secrets.json`、令牌、账号信息或儿童数据。
先说明故障在哪一段：页面 → API、BDS → API、模块加载、媒体播放或课程状态。
